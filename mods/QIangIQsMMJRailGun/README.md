# QIangIQsMMJRailGun

**What it does:** Replaces the Helbore Lasgun with Mullet Mad Jack's rail gun, visual only.

This mod is 111 MB, more than GitHub allows in one file, so it is split into 2 parts.

**Get it:** download all 2 `QIangIQsMMJRailGun.zip.0xx` files and `JOIN_QIangIQsMMJRailGun.bat` into one folder. Then either
- open `QIangIQsMMJRailGun.zip.001` with 7-Zip or WinRAR (they read the other parts by themselves), or
- double-click `JOIN_QIangIQsMMJRailGun.bat`, which makes `QIangIQsMMJRailGun.zip`.

SHA-256 of the joined zip: `ecad87ebdf7aa518571ea6e450cd48031ecb172b213ee3cd949855eb2c2af30c`

**Install:** extract into `Warhammer 40,000 DARKTIDE/mods` so you get `mods/QIangIQsMMJRailGun/QIangIQsMMJRailGun.mod`, then add `QIangIQsMMJRailGun` to `mods/mod_load_order.txt`.
