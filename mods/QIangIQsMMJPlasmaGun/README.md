# QIangIQsMMJPlasmaGun

This mod is 130 MB, more than GitHub allows in one file, so it is split into 2 parts.

**Get it:** download all 2 `QIangIQsMMJPlasmaGun.zip.0xx` files and `JOIN_QIangIQsMMJPlasmaGun.bat` into one folder. Then either
- open `QIangIQsMMJPlasmaGun.zip.001` with 7-Zip or WinRAR (they read the other parts by themselves), or
- double-click `JOIN_QIangIQsMMJPlasmaGun.bat`, which makes `QIangIQsMMJPlasmaGun.zip`.

SHA-256 of the joined zip: `fbe06a6d747c6baed04914b2def1feec1456642cacdcaee5e32f8602f8ed81b6`

**Install:** extract into `Warhammer 40,000 DARKTIDE/mods` so you get `mods/QIangIQsMMJPlasmaGun/QIangIQsMMJPlasmaGun.mod`, then add `QIangIQsMMJPlasmaGun` to `mods/mod_load_order.txt`.
