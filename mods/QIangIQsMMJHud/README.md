# QIangIQsMMJHud

This mod is 144 MB, more than GitHub allows in one file, so it is split into 2 parts.

**Get it:** download all 2 `QIangIQsMMJHud.zip.0xx` files and `JOIN_QIangIQsMMJHud.bat` into one folder. Then either
- open `QIangIQsMMJHud.zip.001` with 7-Zip or WinRAR (they read the other parts by themselves), or
- double-click `JOIN_QIangIQsMMJHud.bat`, which makes `QIangIQsMMJHud.zip`.

SHA-256 of the joined zip: `3a525f6e46653845fff04ba991e480dc798ede1e1b0f057112c6934ed1858d47`

**Install:** extract into `Warhammer 40,000 DARKTIDE/mods` so you get `mods/QIangIQsMMJHud/QIangIQsMMJHud.mod`, then add `QIangIQsMMJHud` to `mods/mod_load_order.txt`.
